### Задание №27

1. Приложение пользователей
Создано Django-приложение users
* Кастомная модель пользователя на основе AbstractUser
* Поля модели:
  * Email (поле для авторизации)
  * Аватар (ImageField)
  * Номер телефона (CharField)
  * Страна (CharField)

2. Система аутентификации
* Регистрация:
   * Форма с полями: email, пароль
   * Отправка приветственного письма
   * Валидация данных
   * Авторизация:
   * Форма входа по email и паролю
   * Кастомный бэкенд аутентификации

3. Контроль доступа
* Защита CRUD-операций:
   * Создание товаров - только для авторизованных
   * Редактирование товаров - только для авторизованных
   * Удаление товаров - только для авторизованных
* Публичный доступ:
   * Просмотр списка товаров - доступно всем
   * Использовано:
   * LoginRequiredMixin для CBV
   * @login_required декоратор для FBV
   * Перенаправление на страницу входа
